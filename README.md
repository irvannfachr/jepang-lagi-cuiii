# ことば道場 | Kotoba Dojo N5

Quiz kosakata Jepang N5 dengan pilihan Bab 1–18, mode campuran, soal tebak arti dan tebak kotoba, keyboard Hiragana/Katakana, sound jawaban, review jawaban salah, dan tampilan responsive untuk HP, tablet, laptop, serta desktop.

## Menjalankan
1. Buka folder ini di VS Code.
2. Pastikan semua file berada dalam satu folder.
3. Jalankan dengan Live Server.

## Catatan
Keyboard Jepang di dalam web dibuat agar pengguna dapat mengetik kana tanpa bergantung pada keyboard sistem. Keyboard bawaan perangkat tetap dapat digunakan untuk kanji.

Created by Irpannn 😎


### Keyboard Jepang compact
Versi ini menggunakan keyboard Jepang yang sepenuhnya ada di dalam website. Input jawaban dibuat read-only sehingga keyboard bawaan HP/laptop tidak muncul. Pengguna cukup menekan tombol Hiragana/Katakana yang tersedia di halaman.
